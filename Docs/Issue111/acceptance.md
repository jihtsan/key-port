# 设置 v2

设计来源：[设置主面板](https://www.figma.com/design/RGpDDMdxvoPwzhlTB5RyiY?node-id=54-2)，以及 55:35、55:70、55:87、55:99 的状态/备份流程。

## 实现

- 独立 WorkspaceSettingsView，640 × 560 顶部对齐的同步与备份分组；使用系统字体、原生按钮/开关/密码控件和适配系统外观的颜色。
- 只检查 CloudKit 可用性即可禁用不可用操作，保留自动同步偏好；可恢复的账户/网络问题提供重新检查入口。
- WorkspaceArchiveFlow 独立管理密码、读取和确认阶段。导出需要非空且一致的密码；导入先选文件再解密，确认前不写入，确认时沿用现有工作区合并规则。
- 临时密码在成功、失败、取消保存后清空；取消关闭时释放解密内容；处理中禁止重复提交和关闭。
- 删除原管理视图中的旧设置与归档分支；文件选择面板文案统一为备份。
