# 统一 Node 身份并分离访问事实

KeyPort 将机器或网络参与者统一建模为 `Node`，不再让 `Host` 和 `Device` 作为两套互斥的机器身份；同一 Node 可以通过角色同时承担客户端设备、SSH 主机、VPN 网关、RDP 主机或服务承载节点。地址、端口、协议和网络范围归入可变的 `Endpoint`，SSH 账户、密钥、授权、主机密钥信任和可达性观测保持独立，因为它们分别表达登录入口、凭据归属、允许关系、远端身份和带时效的本地证据；这样同一台机器可以拥有多个入口和服务，而 Graph 仍只是这些事实的投影。

## 考虑过的方案

- **保留 Host + Device**：无法表达同一台机器同时是本地设备和远端服务节点，也容易把机器身份和访问来源混为两类根实体。
- **把所有字段塞进一个 Host/Device 大对象**：会把地址、协议账户、凭据、服务和观测混成不可维护的“上帝对象”。
- **Node + 角色/档案 + Endpoint + 协议访问关系**：采用此方案；它统一机器身份，同时保留访问和安全事实的独立生命周期。

## 后果

新代码需要重写当前 `HostV6.Host`、`HostV6.Device` 和 endpoint 派生 Host ID 的边界；旧 V5/V6 兼容写路径在迁移完成后可以删除。SSH 作为第一期唯一协议，VPN、RDP 和数据库服务分别在 Node/Endpoint 之上扩展，不需要复制新的机器根实体。
