# 免密触发与服务器列表状态

- 关联：[#119](https://github.com/jihtsan/key-port/issues/119)
- 状态：设计需求，尚未实现。
- 配套：[完整需求](requirements.md)、[设计](design.md)、[验收](acceptance.md)

## 1. 主动、被动分别指什么

主动是用户有意配置当前设备的免密权限；被动是同步或连接过程发现授权条件不足。被动发现不等于自动给服务器写入公钥。本方案不提供默认开启的“同步即自动授权”。

| 触发类型 | 事件 | 应用响应 | 是否立即修改远端 |
| --- | --- | --- | --- |
| 主动设置 | 点击服务器列表/详情的“设置免密” | 当前账户凭据和主机身份均可用时直接进入执行；缺失信息进入同一个设置流程补齐 | 条件满足后执行，不重复询问同一项授权 |
| 主动恢复 | 点击“重试验证”或“重新设置” | 验证重试只测试；重新设置先核对缺失步骤 | 仅“重新设置”按明确操作范围写入 |
| 被动同步 | iCloud/导入带来新的服务器资料或其他设备授权 | 更新列表为“此 Mac 待配置”；可用凭据显示设置入口，缺少时显示补充入口 | 否；不弹出每台服务器的授权窗口 |
| 被动连接 | 用户点击连接，发现当前 Mac 无可用免密身份 | 展示“设置免密并连接”，解释完成后继续本次连接 | 用户确认后执行 |
| 被动发现变化 | 连接失败、主动核对发现公钥消失、主机身份变化 | 显示对应失败或待核对状态；提出恢复动作 | 不自动重装公钥，不绕过身份确认 |
| 状态恢复 | App 启动发现上次任务未完成 | 显示已完成步骤和“待继续/待验证”；先核对事实 | 不把程序启动当作重新授权许可 |

当前 Mac 指当前设备身份，不限定新购买的 Mac。原“02 新 Mac 设置免密”改名“02 当前 Mac 设置免密”，是服务器详情的首次授权流程，不是一级导航或仅新电脑可用的页面。

## 2. 被动发现后的交互

### 同步触发

同步先完成服务器元数据展示，再投影本机授权状态。列表可以显示一条可关闭的汇总提示“已同步 N 台待配置的服务器”，不强制用户逐台处理。关闭提示后条目状态继续保留；相同同步版本不重复弹窗。已有本机验证结果在合法元数据合并后保留，不因为 A 的记录到达就覆盖 B 的本机状态。

若当前 Mac 实际有可用密钥、只是验证证据缺失，显示“待验证”，提供验证动作，不误报为需要重新安装公钥。元数据到达但凭据尚未同步时显示“等待凭据同步”，可以手动提供；凭据到达后更新为可设置，不自动执行。

### 连接触发

点击“连接”代表访问意图。已知当前设备尚未授权时，弹出“设置免密并连接”与“暂不设置”。接受后沿用已保存资料执行，验证成功后继续一次原连接；暂不设置返回列表并保留待配置。操作过程中切换服务器不会把原连接发往新选中服务器，连接上下文必须固定。

SSH 返回一般认证失败时，不能直接断言公钥已被删除：可能是账户、密钥、文件权限或服务端策略问题。显示“认证失败，需检查”；只有成功读取并确认目标公钥缺失时才显示“授权已失效”。连接超时不等于授权消失。

## 3. 服务器列表显示规则（L）

每条服务器显示名称、当前登录账户、主状态和必要的次状态。主状态回答“此 Mac 能否通过这个账户免密访问它”；反向状态回答“这个服务器账户能否免密访问此 Mac”。

| 当前事实 | 主状态 | 次状态示例 | 行内动作 |
| --- | --- | --- | --- |
| 本机缺少授权，凭据可用 | 此 Mac 待配置 | 登录凭据可用 | 设置免密 |
| 本机缺少授权，凭据缺失 | 此 Mac 待配置 | 缺少登录凭据 / 等待凭据同步 | 补充凭据 / 查看同步状态 |
| 有本机身份但缺验证证据 | 免密待验证 | 已有本地密钥 | 验证免密 |
| 正在配置 | 设置免密中 | 核验身份 / 验证凭据 / 安装公钥 | 查看进度 |
| 公钥已安装，测试运行中 | 正在验证免密 | 公钥已安装 | 查看进度 |
| 已安装但测试失败 | 登录验证失败 | 公钥已安装 · 网络超时等具体原因 | 重试验证 |
| 写入前失败 | 设置未完成 | 凭据失效 / 权限不足等具体原因 | 更新凭据 / 查看原因 |
| 实际正向登录成功 | 本机免密已就绪 | 最近验证时间 | 连接 |
| 已验证后发生连接失败 | 连接失败 | 最近曾验证成功 + 本次失败原因 | 重试连接 / 查看详情 |
| 成功核对确认公钥缺失 | 授权已失效 | 指定账户的公钥已不存在 | 重新设置 |
| 主机身份变化 | 服务器身份待确认 | 指纹已变化 | 核对服务器身份 |
| 任务中断且事实未核对 | 设置待继续 | 最后完成步骤，结果待核对 | 查看进度 / 继续 |

双向状态作为独立次状态：反向未开启、反向设置中、反向待验证、反向验证失败、反向免密已验证、反向已撤销。反向失败不抹掉正向成功，正向成功不暗示反向授权。红色“开启双向免密”和撤销动作在服务器详情中，列表不增加默认授予反向权限的捷径。

## 4. 更新、并发与多账户

- 列表和详情使用同一份按当前设备、服务器、登录账户及方向定位的状态；任务只更新自己的目标行。
- 点击行与详情的同一设置动作复用同一任务；执行中禁用重复提交，不再次安装公钥。其他服务器仍可浏览和连接。
- 切换页面不取消任务；用户明确停止时不继续下一步，已写入公钥/配置按事实保留，不显示“从未授权”。强制退出后的恢复先核对状态。
- 任务完成就地更新状态和动作，不默认重新排序或跳走当前选择；失败不删除服务器。自动刷新不抢焦点。
- 同一服务器多个账户时，行状态对应当前选中/明确标识的账户；展示汇总时使用“1/2 个账户免密已就绪”，不得由一个账户成功推断整台服务器全部可用。
- 任务回调绑定稳定服务器/账户/设备 ID 与本次尝试，旧回调不能覆盖新任务或新选择。服务器更名不丢失任务归属。
- 已验证结果显示时间，不视为永不过期承诺。地址、主机身份或目标账户变化时保留历史，并将受影响的连接验证标为待重验。
- 批量自动授权不在本次范围；将来若支持，应由用户明确选择目标集合，而不是由同步事件推导授权意图。
