## 后续实现验收（本次未执行）

| 编号 | 操作 | 必须观察到的结果 |
| --- | --- | --- |
| A01 | 全新工作区打开我的设备 | 当前账户和默认别名预填；密码未保存不阻塞本地公钥安装 |
| A02 | 修改默认别名，再打开双向确认 | 新默认值预填；本次覆盖不改变默认值或其他关系 |
| A03 | 远端已有同名 SSH 配置 | 明确冲突，不覆盖原文件，修正后可以继续 |
| A04 | A 保存 VPS1 密码，B 同步 | 元数据与凭据到达分别显示；B 未验证前不得显示就绪 |
| A05 | B 点击设置免密 | VPS1 安装 B 公钥；B 私钥不离开 B；真实无密码登录成功 |
| A06 | 密码缺失/失效/密码认证关闭 | 分别显示原因及可行下一步，无无限重试或假成功 |
| A07 | iCloud 关闭/失败/凭据不可访问 | 状态真实，允许本次手输；普通备份中不包含密码 |
| A08 | 首次或变化的服务器主机指纹 | 必须先确认可信身份，再发送密码或修改授权 |
| A09 | 正向未验证，尝试双向 | 引导先完成正向；不会自动授予反向权限 |
| A10 | 正向成功后确认双向 | 两向各自验证，VPS1 能使用指定别名登录准确本机账户 |
| A11 | 本机远程登录关闭/地址不可达 | 分别定位原因；已安装公钥明确标记仍存在 |
| A12 | 别名写入失败/安装后崩溃/用户取消 | 恢复时核对已执行步骤；重试不重复写入，不假定回滚 |
| A13 | 当前用户与其他本机账户 | 权限不足明确提示；不自动读取系统密码或绕过系统授权 |
| A14 | 撤销反向授权 | 验证本机身份，指定公钥移除，正向可用，其他公钥保留 |
| A15 | 同公钥复用/对方离线/撤销失败 | 展示真实影响范围；区分本机撤销与别名待清理；失败不报成功 |
| A16 | 删除同步凭据、旧设备重新上线 | 删除不被旧副本覆盖；已存 SSH 授权不被误删 |
| A17 | 核对授权失败或公钥仍在但 SSH 被限制 | 区分读取失败、公钥存在与登录失败，保留时间和执行端 |
| A18 | 640 高窗口、长地址、大字体、键盘和 VoiceOver | 可滚动且操作可达；错误不靠颜色；密码保持隐藏 |
| A19 | 日志、进程参数、工作区、备份检查 | 无明文密码或私钥泄漏 |
| A20 | 两台真实签名 Mac、真实 VPS | 验证凭据同步与两向 SSH；不得以设计截图、mock 或 ad-hoc 构建代替 |
