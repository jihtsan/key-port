## 1. 用户目标与范围

A 已配置目标服务器后，B 通过同一 Apple 账户同步目标服务器资料及用户选择保存的登录凭据，点击“设置免密授权”，即可安装 B 自己的公钥并验证登录。单向免密成功后，可主动点击红色“开启双向免密”，允许目标服务器以指定本机账户反向 SSH 登录。

本次只交付文档和 Figma。后续实现须遵循 Issue → 独立分支 → PR → 验证 → 合并流程。服务器名称、ID、账户、地址和授权关系均来自当前选中的真实对象。VPS1、VPS2、东京开发机仅为示例称呼，不是固定栏目、内置设备或业务判断条件。示例设备、地址、密码掩码与指纹均为设计数据。无需为设计操作真实设备或读取实际凭据。

## 2. 关键定义

| 对象 | 含义 |
| --- | --- |
| 设备 | 持有独立 SSH 身份的 Mac 或远端服务器 |
| 登录账户 | SSH 目标系统中的实际账户；与设备名称、Apple 账户不同 |
| 登录凭据 | 用于首次 SSH 登录的密码等敏感资料；绑定目标设备与账户 |
| SSH 别名 | 存在于连接发起方 SSH 配置中的名称；解析到目标地址、端口、账户和密钥 |
| 授权关系 | 某个来源公钥被安装到某个目标账户，具有明确方向 |
| 公钥核对 | 查看目标账户的授权文件是否包含指定公钥 |
| 登录验证 | 使用来源设备的私钥实际发起 SSH 登录 |

“已同步”“已保存凭据”“公钥已安装”“免密已验证”独立记录。iCloud 记录不能证明远端当前状态，也不能使新设备继承另一台设备的私钥。

## 3. 我的设备配置（D）

我的设备仅配置本机默认信息和连接准备状态，不显示“谁可以登录此 Mac”、服务器列表或每服务器授权操作。服务器关系统一在服务器详情管理。

| ID | 字段 / 能力 | 行为 |
| --- | --- | --- |
| D1 | 设备名称 | 当前 Mac 的展示标识，可修改 |
| D2 | 默认 SSH 别名 | 自动生成并可修改；只影响后续预填，不自动改写已有连接 |
| D3 | 本机登录凭据 | 账户与密码合并在唯一编辑入口；默认账户为当前用户，可修改为其他真实账户 |
| D4 | 连接方式 | 公网 IP / 域名、Tailscale、局域网三种可选配置；无需强制填写公网地址 |
| D5 | 远程登录状态 | 检测 SSH 服务与目标账户允许情况；未开启提供设置引导 |
| D6 | 已保存凭据状态 | 在 D3 区域显示“账户 · 密码已保存”和同步状态，仅提供编辑/移除；不重复创建一份凭据 |
| D7 | 本机公钥信息 | 展示或展开本机公钥指纹、复制能力；其他 KeyPort Mac 可按设备切换查看，不混入服务器授权列表 |
| D8 | 页面边界 | 只提供本机配置；具体服务器的两向状态、测试、公钥核对与撤销属于服务器详情 |

“本机信息”上方不再有独立的登录账户或登录证书表单。此功能不引入 SSH CA 证书登录。双向确认窗口只读引用 D3 的账户和凭据状态，不再次要求输入同一账号密码；需要修改时进入同一个编辑入口，返回后重新核对目标。更换账户不能把原账户密码自动绑定到新账户。编辑时新密码留空表示保持原密码，移除必须使用明确动作。

配置修改需要保存；未保存退出提示保存或放弃。地址更新不自动撤销公钥、不自动替换远端已有别名。

### 3.1 连接方式（N）

| 方式 | 配置与获取 | 状态与限制 |
| --- | --- | --- |
| 公网 IP / 域名 | 手填有效 IPv4、IPv6 或域名及外部 SSH 端口 | 必须实际指向此 Mac；路由器出口 IP 不代表 Mac 已可被入站连接，存在 NAT 时需端口映射；不自动开放路由器或防火墙 |
| Tailscale | 检测本机客户端 → 引导安装/官方登录 → 读取本机 Tailscale IP、可用设备域名 → 保存地址和 SSH 端口 | 没有公网地址也可选择；网络接入成功与 SSH 授权分开记录 |
| 局域网 | 检测或手填本机局域网地址及 SSH 端口，多个接口时允许选择 | 明示仅适用于能够路由到该地址的对方，不承诺公网服务器可直接访问 |

三种方式可分别保存为候选，本机设置默认方式；具体服务器双向确认时选择可达候选，不覆盖默认。未配置公网 IP 时不报必填错误、不阻止 Tailscale 路径。其他组网产品保留扩展点，不显示尚未支持的“授权成功”按钮。

### 3.2 Tailscale 获取与授权流程

1. 未安装：提供官方安装入口；KeyPort 不静默安装系统网络组件。
2. 已安装未登录：按钮“打开 Tailscale 登录”，由官方客户端/浏览器完成身份验证及必要网络扩展许可；KeyPort 不索取 Tailscale 密码。
3. 用户返回：刷新本地客户端状态，只有连接完成并取得本机节点地址才显示“地址已获取”；不能因为浏览器关闭或点击了登录按钮就判定成功。
4. 读取本机节点的 IP 和可用设备域名，不要求用户申请云端 API token、OAuth client secret 或填写设备授权密钥来完成本机地址获取。
5. 未完成登录、等待设备审批、客户端停止、地址缺失或读取失败分别提示；保留重试和手动改用其他连接方式入口。退出登录后旧地址标为待重新验证，不能继续显示已连接。
6. 此处授权的是加入 Tailscale 网络。服务器也须有到该节点的有效网络路径，且网络访问规则允许目标端口；一般由服务器接入同一网络或经明确允许的共享/路由访问。
7. 在服务器详情执行反向 SSH 端口检测与登录验证，才能得出“该服务器能登录此 Mac”。本机地址已获取不等于任意服务器都可达。
8. 本期使用 Tailscale 承载普通 SSH 网络连接，继续使用既有公钥安装流程；不自动启用 Tailscale SSH。若它接管所选端口，须识别认证路径冲突并提供明确提示，不能将普通 authorized_keys 核对结果当作 Tailscale SSH 授权结论。
9. iCloud 可同步所选方式和地址等管理元数据，不同步 Tailscale 会话、设备私有身份或登录票据。新 Mac 仍需完成自身 Tailscale 接入。

技术依据（2026-09-15 核对官方文档）：[普通 SSH over Tailscale](https://tailscale.com/docs/reference/ssh-over-tailscale)、[CLI 状态读取](https://tailscale.com/docs/reference/tailscale-cli?tab=macos)、[Tailscale SSH 的独立认证路径](https://tailscale.com/docs/features/tailscale-ssh)。具体 macOS 客户端调用方式和系统权限需在实现阶段验证。

## 4. 凭据保存与同步（C）

1. 服务器凭据绑定服务器身份与登录账户；本机凭据绑定本机身份与目标账户。禁止用 A 的本机密码当作目标服务器的密码。
2. 保存面板提供“保存并通过 iCloud 同步”的明确选择；取消不保存。首次接入面板也允许只为本次使用，不持久化。
3. 密码输入默认隐藏，展示/更换/移除需适当本机身份验证。只向当前操作提供必要的凭据；不写日志、命令行参数、SSH Config、普通工作区 JSON、Git、截图或元数据备份。
4. 本地保存状态与同步状态分开：未保存、已保存仅本机、同步中、已同步、同步失败；B 还要区分“凭据未到达”与“凭据不可访问”。元数据先到时允许等待/重试或手输。
5. 明确失败原因：凭据缺失、密码失效、服务器不允许密码认证、iCloud 未登录/不可用；提供更新凭据或既有密钥方式，不无休止自动重试。
6. 用户在此 App 修改保存密码仅更新凭据，不修改目标系统密码。删除同步凭据需传播删除标记，防止旧副本恢复；不能承诺擦除其他设备已经读取或另存的副本。
7. 设备更名不重绑凭据；服务器重装/主机指纹变化先进入身份确认与恢复流程，不自动向未知新主机发送旧密码。
8. 私钥留在所属设备；普通备份仍只含管理元数据，不扩大为密码/私钥备份。

### 技术选型待决（不构成已实现承诺）

实现阶段需验证可同步 Keychain 条目或专用加密凭据通道的可行性，明确 entitlement、签名、访问控制、加密密钥分发和恢复策略。普通 CloudKit 元数据同步不等于已经具备密码保险库能力。只有验证新 Mac 能获取凭据，才能显示“凭据可用”。不能未经验证宣称端到端加密、Touch ID 可静默解锁或 ad-hoc 构建支持真实同步。

## 5. B 一键建立正向免密（F）

1. B 同步到目标服务器后显示 A 的授权记录，以及“此 Mac 尚未配置免密”。
2. 点击“设置免密授权”，预填目标服务器地址、账户及可用凭据状态。
3. 核验目标主机身份；首次指纹未知或身份变化时显示确认流程，不自动信任。
4. 为 B 创建或选择本机密钥；用有效登录凭据安装 B 的公钥，避免重复写入。
5. 使用 B 的私钥进行真实非交互 SSH 验证；成功才显示“本机免密已就绪”。
6. 密码只在所需步骤短期可用。安装后断网应显示“公钥已安装，登录待验证”，支持继续测试与精确撤销。

“已有设备代装 B 公钥”可作为后续替代认证能力；本期核心路径是同步的有效服务器凭据，不承诺已实现代装。

## 6. 双向免密（R）

### 入口与确认

在服务器列表选中一个服务器与登录账户后，详情展示“此 Mac → 当前服务器”和“当前服务器 → 此 Mac”的独立状态。正向已验证后显示红色“开启双向免密”；正向未就绪时引导先完成正向免密。我的设备没有服务器授权列表或双向按钮。切换服务器必须重新绑定该服务器的关系状态，不能沿用上一台服务器的结果。

确认窗口列出目标服务器来源账户、本机目标账户、所选连接方式与目标地址/端口、反向 SSH 别名、授权效果与必要的专用密钥创建说明。默认取消，不因 iCloud 同步自动执行。红色表示授予对方本机访问能力，必须附文字说明，不能仅依赖颜色。

### 别名规则

- 预填 D2 默认值，可在确认窗口直接编辑。
- 本次修改只作用于该反向关系，不覆盖设备默认值。
- 写入的是目标服务器上该来源账户的 SSH 配置，不是本机的出站别名。
- 验证非空、合法字符与有效 SSH 配置重名，考虑 Include 与匹配规则；复用已有别名块必须确认属于同一受管理关系。
- 冲突展示替代建议并要求用户选择，不静默覆盖用户配置。只管理 KeyPort 自己的配置块。
- 该别名仅保证在已配置它的来源账户上可用；不宣称所有终端或设备自动可用。

### 执行与验证

1. 检查本机远程登录、目标账户权限和反向地址；本机安装当前用户授权文件通常无需密码，涉及系统设置或其他用户须通过适当系统权限流程。
2. 通过现有正向 SSH 会话，在目标服务器的明确来源账户下创建/选择专用反向密钥。优先每关系专用，私钥留在目标服务器；无可用工具、只读主目录等情况给出失败原因。
3. 将对应公钥安装到本机目标账户，保留其他公钥及选项，记录安装来源与指纹。
4. 为目标服务器写入本机身份验证所需的主机信任信息与受管理别名块；不可关闭主机密钥检查来通过测试。
5. 从目标服务器实际连接到本机目标账户，验证免密成功；分别记录安装、别名写入和登录结果。
6. 正向与反向都验证成功后显示“双向免密已就绪”。地址不可达时不能宣称成功。

## 7. 状态、失败与撤销（S）

每条有向关系至少记录来源设备/账户、目标设备/账户、目标公钥指纹、地址、别名、安装结果、检查时间、验证执行设备与结果。

| 场景 | UI 状态与恢复 |
| --- | --- |
| 仅同步授权记录 | 已记录授权 / 此设备待配置 |
| 公钥已安装，未测试 | 已安装，登录待验证 |
| 远程登录未开启 | 打开远程登录设置，完成后重试 |
| 反向网络超时 | 保留正向成功；显示地址检查和重试 |
| 公钥已安装，别名写入失败 | 提示授权仍存在；重试受管理配置或撤销 |
| 取消/崩溃发生在写入之后 | 保留分步结果；恢复时检查实际状态，不显示未授权 |
| 核对读取失败 | 核对失败，保留最后记录和时间；不得推断已撤销 |
| 主机指纹变化 | 暂停发送凭据/写入，进入明确身份恢复流程 |
| 两向均验证通过 | 双向免密已就绪，显示各自时间与执行端 |

重试使用同一关系标识并核对已有公钥/配置，避免重复安装。取消不等于撤销，安装之后退出需明确保留的权限。

### 撤销反向授权

展示准确来源、目标账户及公钥指纹，经本机身份验证后移除指定授权。只清理属于该关系的内容，不删除无关密钥、配置、日志。正向连接保持不变。

优先采用每关系专用公钥；若已有公钥被多个关系复用，必须列出实际受影响范围，不能声称仅影响一条关系。目标服务器离线不阻止本机撤销，但其别名可能标记为待清理。移除公钥不会主动终止已建立 SSH 会话。读取或写入失败显示“撤销未确认”，核对成功后才显示“已撤销”。不自动删除目标服务器的私钥。

## 8. 现有行为与迁移

当前 WorkspaceManagementView 提供设备改名、公钥展示、账户授权核对和撤销；WorkspaceAuthorization 按目标账户与指纹核对，并依赖此 Mac 已有登录能力。新反向授权不能简单反转 UI 标签复用该路径，必须明确执行端。

当前 WorkspaceSettingsView 声明密码不参与同步，OpenSSHFirstAccessAdapter 仅短期持有首次登录密码。后续实现 C 时须同步更新设置文案、凭据访问层、同步状态和隐私说明；旧工作区无凭据时仍可使用，不能把空值当成空密码。已存在 SSH 授权不得因迁移重新授予反向权限。

## 9. 后续实现拆分

1. 本机配置、唯一凭据入口、默认别名与连接方式；服务器详情关系模型和兼容迁移。
2. Tailscale 客户端接入与本机地址读取；凭据存取及真实双 Mac 同步能力验证，确定选型后实现 C。
3. B 的正向首次授权与失败恢复。
4. 反向密钥、信任、别名安装及逐步验证。
5. 精确撤销、共享公钥范围、异常恢复和原生 UI 验收。

本需求采用普通 SSH 账户权限语义，不承诺受限命令沙箱、团队成员授权、自动打通 NAT、远程启用 macOS 系统服务或会话强制终止。
